# Interzero — Website Concept

A single-page website mockup for **Interzero** (circular economy / "zero waste solutions"),
built as a design concept.

## Design references

The visual language fuses two references:

- **Brass Hands — "Ultra" case study** (brasshands.com): neo-industrial design system —
  heavy condensed uppercase typography, utilitarian monospace spec labels
  (`SYS—01`, `IZ—CS / 01`), stencil-style numbering, flat color blocking.
- **Anduril** (anduril.com): large-format, rhythmic section blocks with short,
  confident taglines ("Sort at scale. Feed the future.").

## Concept

- **Brand line:** "Zero Waste Solutions" with an outlined-text treatment
- **Palette:** warm paper `#efede8`, industrial ink `#131313`,
  circular-economy green `#b7f04a`
- **Hero:** rotating circular-loop diagram (SORT → RECYCLE → RETURN → REUSE around an ∞
  core) plus a scrolling ticker strip
- **Stats:** animated counters based on real Interzero figures (8.1M tonnes primary raw
  materials saved, 80,000+ customers, 10 European countries, 1.0M t CO₂e avoided)
- **Systems:** four alternating light/dark blocks — Circular Solutions, Plastics
  Recycling, Recycling Alliance, Raw Materials & Recyclates — each with a pure-CSS visual
  (animated conveyor, polymer sort grid, licence stack, material bar chart)
- **Also includes:** manifesto section, services grid, news list, CTA, footer

## Structure

```
index.html       — the full single-page site
css/style.css    — design system & layout
js/main.js       — scroll reveals + animated stat counters
```

No build step, no dependencies. Fully responsive.
